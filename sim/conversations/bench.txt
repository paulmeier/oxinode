# Conversations for the simulator: what the Messages screen and a thread
# draw from without a board. `oxinode-sim --conversation FILE` reads another.
#
# `peer <32 hex digits> [name]` starts a conversation; no name is a peer
# that announced none, or has not been heard. Then a message a line:
#
#   <direction> <age> <state>[,unread][,attachment] <text>
#
# `<` is received, its state verified, unverified or bad; `>` is sent, its
# state queued (its turn), queued-path, queued-host, queued-idle; sent,
# sent2 or sent3 (how often it has gone); delivered; failed (no proof) or
# failed-path. The age is in seconds, or `-` for not known. `\n` in the
# text is a newline.
#
# The bench peer's first message is the text Python LXMF sent in the node's
# test vectors (core/src/node/vectors/lxmf.txt), typographic punctuation and
# all; the rest is written to show one thing each.
